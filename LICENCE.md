## 🧩 About

**Hades 2 Overlay Menu** is a curated list of Hades 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, resource tracker
- **Quality-of-Life Helpers** — boon catalog, inventory manager, overlay notes
- **Research Notes** — combat layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Resource Tracker — keep track of health, mana, and gold
- Show Hitboxes — visualize enemy and projectile hitboxes
- Combat Log — record and review combat encounters
- Game Speed — adjust game speed for study (0.1x to 3x)

### Wallhack
- Boon Catalog — browse boons, upgrades, and rarities
- Custom Skin Notes — organize character cosmetics
- Improved Visibility — highlight interactable objects

### Aimbot
- Practice Mode Notes — segment study on any encounter
- Room Layout Viewer — see room structure and exits
- Dash Cooldown Notes — chain dashes in the editor
